# AI Engineering Skills Map — 一套开放的学习协议

以吴恩达（Andrew Ng）2026 年 8–9 月发布的 **The AI Engineering Skills Map** 为骨架，构建的一套有来源支撑、简单易上手的学习手册。

根据原版公开信的内容，给每一个子技能都配一份手册，包含零术语的上手入口、需要掌握的概念清单、底层的原理，以及一组可以用来检验自己是否学会的能力检查点。

[English →](README.md)

## 为什么做这件事

2026 年 8 月，吴恩达与 DeepLearning.AI 发布了一张 AI 工程技能图谱。它基于 10,000 多份招聘启事的分析、数十次专家访谈与问卷数据综合得出，列出四个顶层技能，并拆解为 20 个子技能。

这张图谱是一份很好的索引，但它很薄——每个子技能只有一到两段话。它告诉你**该学什么**，但不足以让你真的学会。

本仓库补的就是这一段。每个子技能一份独立手册，以图谱原本的定位为锚点，在其上搭建真正的深度，全程标注一手来源（论文、官方文档、实践者撰写的文章）。

## 推进管线（pipeline）

原始几封信构成主干，学习顺序即按它们展开：

| 阶段 | 内容 |
|---|---|
| 0 | 总览信——图谱全貌，四大技能一览 |
| 1 | **构建与部署 AI 应用**——6 个子技能 |
| 2 | **软件工程基础**——5 个子技能 |
| 3 | **使用编程 Agent**——5 个子技能 |
| 4 | **塑造构建**——4 个子技能 |

每个阶段内部按顺序推进子技能。所有手册遵循同一套六段式模板，格式很快就能熟悉，注意力可以全部放在内容上。

## 文档格式

每份手册固定六段：

1. **概述**——这个技能是什么、为什么重要，不带术语说清楚
2. **图谱中的定位**——原文究竟怎么说，附链接
3. **核心概念**——需要知道的菜单式清单
4. **深入原理**——底层原理、已知偏差、反直觉的结论
5. **能力检查点**——你应该能做出的陈述，用来自测
6. **来源**——全部引用，附链接

第 1–2 段是上手坡道，第 3 段是工作性知识，第 4 段承载深度，第 5–6 段是它成为「协议」而非「文章合集」的关键。
